# Лабораторная работа № 1

Тема: установка и конфигурация операционной системы на виртуальную машину.

Состав локального пакета:

- `report/infosec-intro-lab01-report.qmd` — редактируемый исходник отчёта;
- `report/_output/` — собранные PDF и DOCX;
- `presentation/infosec-intro-lab01-presentation.qmd` — исходник презентации;
- `presentation/_output/` — презентация PDF и самодостаточный HTML;
- `report/image/` и `presentation/image/` — кадрированные изображения из записи OBS; кадр оставляет интерфейс VirtualBox/гостевой системы и не включает область веб-камеры.
- `presentation/image/student-portrait.png` — портрет докладчика, предоставленный автором.

## Сборка

Из соответствующей папки запустить:

```powershell
quarto render
```

Для отчёта команда создаёт PDF и DOCX; для презентации — PDF и HTML. Проект подготовлен на основе шаблонов курса в `template/report` и `template/presentation`.

Архив `infosec-intro-lab01-source.zip` содержит исходники, шаблонные ресурсы и иллюстрации; собранные PDF и HTML хранятся отдельно в каталогах `_output/` и предназначены для релиза.

## Перед публикацией

1. Просмотреть отчёт и презентацию и внести правки после записи скринкастов подготовки.
2. Записать скринкасты выполнения, подготовки отчёта, подготовки презентации и защиты. Сверить площадки перед загрузкой: карточка переаттестации ТУИС называет Rutube и VK Видео, а ФОС курса — Rutube и PLVideo.
3. Создать GitVerse-репозиторий для курса, опубликовать ту же историю проекта и релиз с файлами отчёта, презентации и архивом исходников.
4. Добавить ссылки в ответ ТУИС. Перед отправкой проверить точную карточку и получить подтверждение владельца аккаунта.
