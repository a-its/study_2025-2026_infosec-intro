C1 = P1 XOR K; C2 = P2 XOR K.
C1 XOR C2 = P1 XOR K XOR P2 XOR K = P1 XOR P2.
Причина: XOR коммутативен и ассоциативен, K XOR K = 0.
P2 = C1 XOR C2 XOR P1; P1 = C1 XOR C2 XOR P2.
На известных позициях P1 восстанавливаются те же позиции P2.
Полное восстановление в опыте использует шаблон P1 и догадку Банка в P2.
При восстановлении ключ не был входом и не вычислялся.
Из одних C1 и C2 нельзя гарантировать единственность исходных текстов.
Результат догадки проверен сравнением с исходными учебными телеграммами.
Для другого сообщения нужна новая независимая секретная гамма.
