# Приложение для исследования повторного использования гаммы

Python 3.8 или новее, только стандартная библиотека. Текстовые файлы UTF-8;
перед XOR сообщения кодируются в cp1251. Шифротексты и ключ записаны в HEX.

```bash
python3 keyreuse.py --help
python3 keyreuse.py encrypt --text-file issuer/p1.txt --key-file issuer/key.hex --out new-c1.hex
python3 keyreuse.py decrypt --cipher-file issuer/c2.hex --key-file issuer/key.hex --out new-p2.txt
cd attacker
python3 keyreuse.py recover --c1-file c1.hex --c2-file c2.hex --known-text 'НаВашисходящийот' --offset 0 --out new-prefix.txt
```

Выходные файлы создаются без перезаписи. Для повторения использовать новые имена.
В режимах xor и recover ключ не является входом и не вычисляется.
Из одних шифротекстов нельзя гарантировать единственное прочтение: нужен известный
текст или проверяемая смысловая гипотеза.

Исходник идентичен исполненному по SHA-256, видимому в записи от 12.10.2026.
Файлы телеграмм, HEX и таблица реконструированы по сценарию и сверены с записью;
это не копии файлов, извлечённые из гостевой ОС. session.log и гостевой архив
lab08-evidence.tar.gz на Windows не перенесены и в этом комплекте не воспроизводятся.
Учебный ключ опубликован для воспроизведения опыта и не предназначен для переписки.
