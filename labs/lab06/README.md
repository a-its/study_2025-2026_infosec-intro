Ицков Андрей Станиславович, НФИбд-03-24. Работа выполнена 12.10.2026 в Rocky Linux 9.8, SELinux targeted, Enforcing.

В отчёте исследованы контексты Apache и файлов, состав политики, отказ чтения страницы с типом samba_share_t и отказ привязки к TCP 81 с локальным типом reserved_port_t. Снимки взяты из записи выполнения; их временные отметки указаны в подписях. Контрольные вопросы, отличия от методички и восстановление стенда включены в отчёт.

## Файлы и сборка

- `report/infosec-intro-lab06-report.qmd` и `.md` — одинаковые исходники отчёта; `report/image/` — 31 снимок из записи.
- `presentation/infosec-intro-lab06-presentation.qmd` и `.md` — одинаковые исходники презентации из 19 слайдов.
- `code/test.html`, `code/apache-experiment.conf.txt` — содержимое страницы и изменённые директивы Apache.
- `code/restore.sh`, `code/functions.sh` — сценарий восстановления с исправлением условного вызова reset-failed и его вспомогательная функция.
- `lab06-sources.zip` — исходники, ресурсы и самодостаточная HTML-презентация.

Для сборки нужны Quarto, LuaLaTeX и шрифты шаблона. Из каталога `report/` выполнить `quarto render`; затем, при установленном python-docx, `python format_docx.py` для оформления DOCX. Из каталога `presentation/` выполнить `quarto render`. Результаты создаются в соответствующем `_output/`.

## Зависимости сценария восстановления

Сценарий выполнялся от root в лабораторной ВМ и использовал каталог `/root/lab06-state/`, созданный до опытов: `state.env`, `functions.sh`, резервную копию `httpd.conf.before` и маркеры изменений. В `state.env` сохранялись переменные `lab06_mode_before`, `lab06_httpd_before`, `lab06_port81_before`. Для данной записи их исходные значения: Enforcing, inactive, http_port_t; отдельной локальной настройки TCP 81 не было. Сценарий возвращает именно это предварительно сохранённое состояние и не является универсальной настройкой для другого сервера.
